# Jedra do Više obale → Sails to the Higher Shore: glossary (sr → en)

Names of people, villages and the ship stay the same (Lovro, Mina, Ratko, Hana, Savo, Sena, Jaro, Pesak, Gvožđe, Burad, Dugi Dah, Rojna). Ordinary-word place and institution terms are translated; the choice below is used throughout the story. American spelling. English path: `higher-shore`.

## Places, institutions

| Serbian | English | Note |
| --- | --- | --- |
| Jedra do Više obale | Sails to the Higher Shore | title |
| Viša obala | the Higher Shore | destination; the gate stands on it |
| Niska obala | the Lower Shore | the sinking shore |
| Dugi Dah | the Dugi Dah | the ship; stays, with “the” in English |
| Rojna | Rojna | the planet; only in the description |
| Zavod Višeg dana | the Board of the Higher Day | “the Board” for short; only a gate and a list |
| kapija | the gate | the gate of the Higher Shore |
| Pesak, Gvožđe, Burad | Pesak, Gvožđe, Burad | villages; stay |
